# AI TRIP PLANNER

Welcome to the AI Trip Planner! This web application helps users plan their trips efficiently by generating an itinerary based on the number of travelers, budget, and destination preferences. Users can create an account, log in, and view past trips or plan new ones seamlessly.

## Features
- User authentication (Sign in/Sign up) with Firebase.
- Input-based trip recommendations (group type, price range, destination).
- Generates a customized itinerary with recommended hotels and places to visit.
- Displays the best times to visit suggested locations.
- Save and view previously planned trips.
- Responsive, mobile-friendly design.

## Usage
1. Sign up or log in to the AI Trip Planner.
2. Enter trip details such as:
   - Number of travelers
   - Group type (couple, family, or group)
   - Price range (cheap, moderate, luxury)
   - Destination
3. The app will generate a list of hotels and places to visit based on your preferences.
4. View a recommended itinerary, including the best times to visit each location.
5. Save your trip or view previous trips.
